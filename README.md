# NEXORA — Операционная система цифровой компании

NEXORA — платформа для управления цифровым персоналом на базе ИИ.
Командный центр, цифровые сотрудники, задачи (Kanban), артефакты,
согласования, интеграции, аудит и биллинг — в едином интерфейсе.

🌐 **Демо:** [aicompany.abacusai.app](https://aicompany.abacusai.app)
📖 **English version:** [README.en.md](README.en.md)

---

## Возможности

- **Дашборд** — сводка по активности компании, задачам и расходам.
- **Цифровые сотрудники** — создание ИИ-агентов с настраиваемыми ролями, инструкциями и бюджетами.
- **Задачи (Kanban)** — доска задач с приоритетами, статусами и привязкой к исполнителям.
- **Артефакты** — версионируемые результаты работы ИИ-агентов.
- **Согласования (Human-in-the-loop)** — механизм ревью и утверждения результатов.
- **Аудит** — полный журнал событий для прозрачности действий.
- **Интеграции** — каталог подключаемых внешних сервисов.
- **Биллинг** — внутренний учёт операционных расходов по тарифным планам.
- **Настройки** — конфигурация профиля компании и участников.

## Быстрый старт (Docker Compose)

В комплект входит `docker-compose.yml`, который поднимает **приложение + базу данных**
одной командой.

1. Скопируйте файл с переменными окружения и заполните его:

   ```bash
   cp .env.example .env
   ```

2. Сгенерируйте секреты для авторизации и впишите их в `.env`
   (`NEXTAUTH_SECRET` и `AUTH_SECRET` могут быть одинаковыми):

   ```bash
   openssl rand -base64 32
   ```

3. *(Опционально, но нужно для реального исполнения ИИ-задач)*
   Впишите в `.env` ваш `ABACUSAI_API_KEY`.
   Получить ключ: https://apps.abacus.ai/chatllm/admin/api-keys

4. Запустите:

   ```bash
   docker compose up --build
   ```

   При первом запуске схема базы данных создаётся автоматически
   (`prisma db push`), а демо-данные засеиваются (`SEED_ON_START=true`).

5. Откройте приложение: **http://localhost:3000**

### Демо-доступ (после сидинга)

| Поле     | Значение          |
|----------|-------------------|
| Логин    | `demo@nexora.app` |
| Пароль   | `demo1234`        |
| Компания | Northwind Labs    |

> После первого запуска можно выставить `SEED_ON_START=false`, чтобы не
> пересеивать демо-данные при каждом рестарте.
> Сидинг идемпотентный (через `upsert`) и не удаляет данные.

## Запуск со своей внешней базой данных

Если у вас уже есть PostgreSQL:

```bash
docker build -t nexora .

docker run -p 3000:3000 \
  -e DATABASE_URL="postgresql://user:password@host:5432/dbname" \
  -e NEXTAUTH_SECRET="<сгенерированный секрет>" \
  -e AUTH_SECRET="<тот же секрет>" \
  -e ABACUSAI_API_KEY="<ваш ключ>" \
  -e SEED_ON_START=true \
  nexora
```

Контейнер при старте сам применит схему к базе и засеет демо-данные.

## Переменные окружения

| Переменная          | Обязательна | Назначение                                                 |
|---------------------|-------------|------------------------------------------------------------|
| `DATABASE_URL`      | да          | Строка подключения к PostgreSQL                            |
| `NEXTAUTH_SECRET`   | да          | Секрет для подписи сессий                                  |
| `AUTH_SECRET`       | да          | То же значение, что и `NEXTAUTH_SECRET`                    |
| `ABACUSAI_API_KEY`  | для ИИ      | Ключ для реального исполнения задач ИИ-агентами            |
| `AWS_REGION`        | опционально | Регион S3-хранилища (для загрузки файлов)                  |
| `AWS_BUCKET_NAME`   | опционально | Имя бакета S3                                              |
| `AWS_FOLDER_PREFIX` | опционально | Префикс папки в бакете                                     |
| `SEED_ON_START`     | опционально | `true` — засеять демо-данные при старте                    |

> ⚠️ **Внимание:** Никогда не коммитьте файл `.env` в репозиторий.
